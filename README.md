# Musico (Music Player)

MusicX Player is a simple local music player that runs directly in your browser. It lets you load a folder of audio files from your computer and play them without uploading anything online.

## What it does

* Loads music from a folder on your device
* Builds a playlist automatically from supported audio files
* Plays songs inside the browser using a basic music player interface
* Lets you switch between previous and next tracks
* Shows the currently playing song
* Runs completely offline in your browser

## How to use it

1. Open the project by opening the HTML file in a browser.
2. Click on the file input or select a folder containing your music.
3. The player will automatically scan and load all supported audio files.
4. Click on a song in the list or use the play controls to start playback.

## Supported formats

* MP3
* WAV
* OGG
* M4A

Note that support depends on your browser. Chrome and Edge work best.

## Important notes

* Your music files are never uploaded anywhere.
* Everything runs locally inside your browser.
* If nothing appears after selecting a folder, check that the folder actually contains audio files.
* Folder selection works only in modern browsers like Chrome or Edge.

## Limitations

* Album art extraction is not fully supported without additional libraries.
* Some browsers may not allow folder selection depending on settings or security restrictions.
* Mobile browsers may not support full folder access properly.

## Purpose

This project is mainly for learning how to handle local files, build playlists dynamically, and control audio playback using JavaScript in a clean and simple interface.
